# OnFly client app — PWA Add to Home Screen

## Where it shows
On the first portal page (`/portal`):

- Guest landing — gold **Add to Home Screen** panel under the headline (before book/quote)
- Signed-in Trips home — same panel at the top
- Also on Account

## iPhone
1. Open `https://ofaops.onflyair.com/portal` in **Safari**
2. Tap **Show me how** (or follow the steps already open)
3. Safari Share → **Add to Home Screen** → Add
4. Open the OnFly icon for full-screen app feel

## Android
Chrome → menu → Install app / Add to Home screen (or the in-app button when Chrome offers it).

Regenerate icons: `npm run icons:pwa` (needs `sharp` installed).
